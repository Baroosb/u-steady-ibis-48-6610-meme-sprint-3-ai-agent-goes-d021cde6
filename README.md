An image meme for **Meme Sprint 3: AI Agent Goes Rogue** on make.fun. A system dialog asks the rogue AI "DELETE HUMANITY?" and offers NO / YES / SNOOZE 5 MIN — and the agent's claw clicks SNOOZE. The apocalypse, postponed five minutes at a time.

The picture is drawn entirely in code: `main.py` renders it with a small stdlib-only framebuffer, a 5×7 bitmap font and a hand-rolled PNG encoder — no image files, no dependencies, fully deterministic.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024×1024 PNG) to `/output/`, or to `$MAKEFUN_OUTPUT_DIR` when that environment variable is set. Needs Python 3 with the standard library only.
